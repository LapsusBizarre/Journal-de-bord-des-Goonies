PROBLÉMATIQUE 1 - Archive manquante


Énoncé / Descriptif

Contexte : Les services secrets Velmorasiens indiquent qu'une exfiltration de données a eu lieu sur une base de données contenant des images satellites de surveillance du territoire Poskave. Cette fuite est suivie de très près car elle contient des éléments compromettants.

Objectif : Analyser la différence entre l'image originale et l'image volée pour extraire le message caché.


Résolution : démarche détaillée

Étape 1 : Analyse des signatures

Vérification de l'intégrité binaire des fichiers : bien que visuellement identiques, les fichiers présentent des signatures numériques différentes.

Étape 2 : Comparaison binaire

Utilisation d'un algorithme de comparaison pixel par pixel pour isoler les données additionnelles (stéganographie).

Étape 3 : Extraction du Flag

Récupération du message brut et application d'une substitution (i -> 1) pour obtenir le flag valide final.

Difficulté(s) rencontrée(s)

La difficulté majeure a été de trouver un outil capable d'isoler précisément les changements de pixels sans dénaturer l'image originale.

Ce que j'ai appris

  • Vérifier l'intégrité d'un fichier via sa signature.
  • Comprendre les principes de la stéganographie visuelle.
  • Appliquer un post-traitement (substitution) sur un flag brut.

Grand Oral : ce que je peux réutiliser

Cet exercice permet d'illustrer les méthodes d'exfiltration de données lors de conflits cyber-géopolitiques entre deux puissances.
